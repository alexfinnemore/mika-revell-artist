# RFP Intake

Parse RFP documents and extract structured requirements for Living Matter Studio proposals.

## Instructions

1. **Locate RFP Documents**
   - Check `/rfps/[active-proposal]/reference/` for PDF files
   - Read any existing intake notes

2. **Extract Key Information** into these sections:

   **BASIC DETAILS**
   - Institution/Organization
   - Project title
   - Budget amount
   - Submission deadline (date, time, timezone)
   - Project timeline/installation dates
   - Location

   **ELIGIBILITY & RESTRICTIONS**
   - Who can apply
   - Geographic restrictions
   - Solo vs collaborative allowed
   - Disqualifying factors

   **PROJECT REQUIREMENTS**
   - Size/scale parameters
   - Required materials or constraints
   - Conceptual themes or guidelines
   - Site-specific considerations
   - Community engagement requirements
   - Process vs product focus

   **SUBMISSION SPECIFICATIONS**
   - Required documents list
   - File formats and size limits
   - Visual materials needed (number of images, dimensions)
   - Word/page count limits for each section
   - Submission method and portal

   **SELECTION PROCESS**
   - Committee composition
   - Review timeline
   - Evaluation criteria
   - Notification dates

   **CONTACTS**
   - Question contact person
   - Email and phone numbers

3. **Strategic Analysis**
   - List 3 unique opportunity aspects
   - Identify 2-3 potential challenges
   - Rate alignment with Living Matter's practice (High/Medium/Low)
   - Note any connection to Mika's prior Japan residency (AIR 3331, 2016)

4. **Create Output File**
   - Save as `00-intake.md` in the active proposal folder
   - Use exact section headers above
   - Flag anything unclear or missing

## Output Location

`/rfps/[active-proposal]/00-intake.md`
